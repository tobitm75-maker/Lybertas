# Produkt-Screenshots

Hier die echten App-Screenshots ablegen. Die Startseite bindet sie automatisch
ein (bis dahin zeigt sie beschriftete Platzhalter). Empfohlen: PNG, ~2×-Auflösung,
gleicher Zuschnitt je Gruppe (ideal 16:10).

Erwartete Dateinamen:
- hero-dashboard.png          → Hero (Haupt-Produktbild)
- karte-maengelmelder.png     → Funktionen: Karte & Mängelmelder
- umfragen-abstimmungen.png   → Funktionen: Umfragen & Abstimmungen
- mitarbeiterplattform.png    → Funktionen: Mitarbeiterplattform
- personalisierung.png        → Für Kommunen: Musterstadt (personalisiert)
